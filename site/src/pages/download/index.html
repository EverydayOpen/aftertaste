Download Aftertaste

Free and open source. {{status}}

Open GitHub Releases View source

macOS {{minMacOS}} or later · Apple silicon and Intel · MIT licence

  1. Download from ReleasesTake the latest build from GitHub Releases and check it against the SHA256SUMS (or .sha256) file attached to the same release, not the editable notes: run shasum -a 256 -c next to the download. Use no other site, and never paste a Terminal command to install it.
  2. Move Aftertaste to ApplicationsOpen the download and drag Aftertaste into the Applications folder.
  3. Open it the first timePublic builds are unsigned betas until there is a Developer ID, so macOS blocks the first launch. On macOS 13 and 14, right-click Aftertaste, choose Open, then Open again. On macOS 15 or later, open it once, then go to System Settings › Privacy & Security and choose Open Anyway.

Or build it yourself

Everything is in the repository. You need a Mac with Xcode and XcodeGen; the steps are in the README.

Aftertaste needs no permissions, makes no network connections and is not affiliated with or endorsed by any app it detects. Moving files to the Trash can be undone until you empty the Trash; read what it reads and what it never does first.

Only from github.com/{{releasesRepo}}/releases. Aftertaste is free: anyone asking you to pay for it is not us.
